# Feishu Document Writer Skill

## Overview

Complete workflow for writing into Feishu documents from any AI tool or script.
Works with Claude Code, Cursor, GitHub Copilot/Codex, or any Python/Node.js script.

## Authentication

```python
import requests

def get_feishu_token(app_id: str, app_secret: str) -> str:
    r = requests.post(
        "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal",
        json={"app_id": app_id, "app_secret": app_secret}
    )
    data = r.json()
    if data["code"] != 0:
        raise RuntimeError(f"Auth failed: {data}")
    return data["tenant_access_token"]  # valid ~2 hours
```

## Feishu App Setup (one-time)

1. [open.feishu.cn](https://open.feishu.cn) → 创建自建应用
2. 应用能力 → 添加**机器人**
3. 权限管理 → 开通：
   - `docx:document:write_only`（应用身份）← **必须**
   - `docx:document:readonly`（应用身份）
4. 版本管理与发布 → 申请发布
5. 飞书文档 → 分享 → 设为**组织内所有人可编辑**
   （机器人无法通过邀请协作者方式添加，组织内权限是唯一可行方案）

## Write blocks to document

```python
def write_to_feishu(token: str, doc_token: str, blocks: list):
    """doc_token is also the root block ID."""
    r = requests.post(
        f"https://open.feishu.cn/open-apis/docx/v1/documents/{doc_token}/blocks/{doc_token}/children",
        headers={"Authorization": f"Bearer {token}", "Content-Type": "application/json"},
        json={"children": blocks}  # max 50 blocks per call
    )
    result = r.json()
    if result["code"] != 0:
        raise RuntimeError(f"Write failed: {result}")
    return result
```

## ⚠️ Critical: block_type=2 uses "text", NOT "paragraph"

```python
# ✅ Correct
{"block_type": 2, "text": {"elements": [el("Hello")], "style": {"align": 1}}}

# ❌ Wrong — returns error 1770001 invalid param
{"block_type": 2, "paragraph": {"elements": [el("Hello")]}}
```

## Block types

| block_type | field | description |
|-----------|-------|-------------|
| 2 | `text` | paragraph |
| 3 | `heading1` | H1 |
| 4 | `heading2` | H2 |
| 5 | `heading3` | H3 |
| 12 | `bullet` | bullet list item |
| 22 | `divider` | horizontal line |

## Copy-paste helper functions

```python
def el(text: str, url: str = "") -> dict:
    """Text element, optionally with hyperlink."""
    style = {}
    if url:
        style["link"] = {"url": url}
    return {"text_run": {"content": text, "text_element_style": style}}

def block(btype: int, elements: list) -> dict:
    """Any text-based block."""
    names = {2: "text", 3: "heading1", 4: "heading2", 5: "heading3", 12: "bullet"}
    return {"block_type": btype, names[btype]: {"elements": elements, "style": {"align": 1}}}

def divider() -> dict:
    return {"block_type": 22, "divider": {}}
```

## Full example

```python
import requests, datetime, os

token = get_feishu_token(os.environ["FEISHU_APP_ID"], os.environ["FEISHU_APP_SECRET"])
doc   = os.environ["FEISHU_DOC_TOKEN"]
today = datetime.date.today().strftime("%Y年%m月%d日")

blocks = [
    block(3, [el(f"📋 {today} Report")]),
    block(2, [el("Auto-generated by Claude Code")]),
    block(4, [el("Section 1")]),
    block(12, [el("Item with link", url="https://example.com"), el(" – description")]),
    block(12, [el("Another item")]),
    divider(),
]

# Batch if >50 blocks
for i in range(0, len(blocks), 50):
    write_to_feishu(token, doc, blocks[i:i+50])
```

## Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| `1770001 invalid param` | Wrong block field name | Use `"text"` not `"paragraph"` |
| `10014 app secret invalid` | Wrong secret | Reset in Feishu open platform |
| Write fails but GET succeeds | Permission mismatch | Ensure `docx:document:write_only` is 应用身份 |
| Bot not found in doc sharing | Expected behavior | Use org-wide editable setting instead |
